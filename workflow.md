🧩 Общая логика

Workflow называется “Check calls” и предназначен для автоматического анализа записей звонков, которые появляются в папке Google Drive.
Он автоматически:

Отслеживает новые или обновлённые файлы-записи звонков.

Скачивает аудио.

Делает транскрибацию.

Отправляет текст в LLM (GPT-4o-mini) для:

разметки “клиент / продавец”;

анализа по чек-листу качества звонка;

Определяет, кто из менеджеров говорил (Елизавета / Владимир / Надежда);

Сохраняет структурированные оценки и транскрипт в соответствующую Google-таблицу.

🚀 Последовательность узлов и их функции
1. Google Drive Trigger

Слушает папку с ID 1qb_o_yLNWVR8_LK98zKHstuEDNxNmGJW
(название папки — “Звонки”)

Срабатывает при обновлении файла (event: fileUpdated).

Период опроса — каждую минуту (pollTimes → everyMinute).

🔹 Назначение: стартует весь процесс, когда появляется или обновляется новая запись звонка.

2. Download file (Google Drive)

Берёт id из триггера ({{ $json.id }}).

Скачивает сам файл (обычно .mp3 / .wav).

🔹 Назначение: получает аудио для дальнейшей транскрибации.

3. Transcribe (OpenAI / LangChain node)

Использует operation: transcribe, resource: audio.

Подключен к OpenAi myAccount.

Делает распознавание речи в текст (транскрибация).

🔹 Выход: текстовая версия разговора ($json.text).

4. Message a model (GPT-4o-mini)

В prompt подаётся транскрибированный текст.

Инструкция модели:

Разбить сплошной текст на реплики;

Добавить перед каждой строкой Продавец: или Клиент:;

Использовать список имён менеджеров:
Елизавета, Владимир, Надежда;

Не изменять структуру, не сокращать, только размечать роли.

🔹 Выход: та же транскрибация, но с пометками кто говорит.

5. AI Agent2 (LangChain agent)

В prompt получает:

Текст аудио: {{ $json.message.content }}

System-инструкцию на русском:

Определить тип звонка — входящий или исходящий;

Пройтись по всем этапам (ПРИВЕТСТВИЕ, УСТАНОВЛЕНИЕ КОНТАКТА и т.д.);

Для каждого чек-пункта выставить оценку 1, 0.5 или 0;

Вернуть строго один JSON-объект по заданной структуре.

Пример JSON-шаблона указан прямо в prompt.

🔹 Выход: готовый JSON со всеми оценками + типом звонка.

6. OpenAI Chat Models и Output Parsers

Эти узлы обеспечивают корректную работу и форматирование результата:

OpenAI Chat Model2 и OpenAI Chat Model4 — оба используют GPT-4o-mini;

Auto-fixing Output Parser — чинит возможные ошибки формата;

Structured Output Parser — применяет строгую схему JSON (пример структуры из prompt).

🔹 Назначение: гарантировать, что ответ AI строго соответствует JSON-схеме.

7. Switch (определение менеджера)

Проверяет, кто из менеджеров упомянут в тексте:

Если в транскрипции есть слово “Владимир” → outputKey: “Владимир”

Если есть “Надежда” → outputKey: “Надежда”

Если есть “Елизавета” → outputKey: “Елизавета”

🔹 Назначение: выбрать правильный лист для записи данных.

8. Google Sheets Append (по менеджерам)

Три одинаковых узла, отличаются только листом:

Входящие Елизавета

Входящие Надежда

(аналогично для Владимира)

Каждый:

Пишет в таблицу:
https://docs.google.com/spreadsheets/d/1V2ERVA_VOraJiRTxCrSW1AUQeBYUG3XkFldQQTqrU5w/

Передаёт все показатели из JSON по конкретным чек-пунктам:

приветствие, контакт, презентация, сомнения, завершение;

суммы по этапам и общий балл ВСЕГО;

полный текст транскрипции.

🔹 Назначение: сохраняет в аналитическую таблицу оценку звонка и сам текст.

⚙️ Поток данных (в Python-логике)

Если переписать как Python-цепочку, то логика выглядит так:

def main():
    file = wait_for_new_file(folder_id="1qb_o_yLNWVR8_LK98zKHstuEDNxNmGJW")
    audio = download_from_drive(file.id)
    text = transcribe_audio(audio)
    dialogue = gpt4_tag_roles(text)
    analysis = gpt4_analyze_call(dialogue)
    manager = detect_manager(dialogue)
    save_to_sheet(analysis, dialogue, manager)

📈 Резюме функциональных блоков
Этап	Инструмент	Назначение
1	Google Drive Trigger	Отслеживание новых аудио

3	OpenAI Transcribe	Распознавание речи
4	GPT-4o-mini	Разметка ролей “клиент / продавец”

8	Google Sheets Append	Запись результата в нужный лист
